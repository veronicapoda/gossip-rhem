# Hyperevent network modelling of partially observed gossip data

This repository contains the code used for the simulation study and empirical application presented in the paper: "Hyperevent network modelling of partially observed
gossip data".

Traditional inferential techniques for relational event models typically rely on fully observed event sequences. However, in many real-world networks, events are only partially observed, which poses challenges for standard likelihood-based methods. In this paper, we build on the Relational Hyperevent Model (RHEM) to analyze higher-order interactions, such as gossip involving multiple individuals, and employ a framework that accommodates partially observed data. By introducing a *right-censored full likelihood* approach, we are able to estimate relevant effects in a gossip case study, capturing both linear and smooth effects as well as unobserved heterogeneity. We demonstrate the method’s effectiveness through a simulation study, showing how it recovers covariate effects in the presence of right censoring and highlighting the advantages of explicitly accounting for censoring compared to standard approaches when data are missing, as is often the case in surveys. Finally, we provide an empirical application to gossip using longitudinal data from over 40 secondary school communities in Hungary, uncovering the temporal dynamics and social drivers of gossip.
